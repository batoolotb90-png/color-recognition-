OpenCV Color Recognition

## Project Description

This project is developed using Python and OpenCV to recognize colors in real time through a webcam.

The program detects three colors:
- Red
- Green
- Blue

When a colored object is placed in front of the camera, the program detects it, draws a rectangle around the object, and displays the detected color name on the screen.

---

## Technologies Used

- Python 3.14
- OpenCV
- NumPy
- Anaconda
- Visual Studio Code
- Git
- GitHub

---

## Requirements

Install the required libraries using:

```bash
pip install -r requirements.txt
```

---

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the project:

```bash
python main.py
```

5. Place a red, green, or blue object in front of the webcam.

6. Press **Q** to close the camera.

---

## Project Features

- Real-time color recognition using a webcam.
- Detects Red, Green, and Blue colors.
- Draws a rectangle around the detected object.
- Displays the detected color name.
- Fast and easy to use.
- Built using OpenCV and Python.
